پروژه مستقل پژوهشی TradingAgents برای طلا است و به ربات‌های قبلی متصل نیست.

در GitHub روی Code سپس Codespaces و Create codespace کلیک کنید. نصب وابستگی‌ها با setup.sh انجام می‌شود.

برای استفاده از مدل‌های هوش مصنوعی، کلیدهای لازم را فقط در Codespaces Secrets وارد کنید؛ هیچ توکن یا رمز عبوری را داخل مخزن عمومی ذخیره نکنید.

قبل از اجرای داده‌های تاریخی، باید اطمینان حاصل شود که اخبار و داده‌ها فقط از اطلاعات موجود در همان تاریخ استفاده می‌کنند. گزینه confirm-historical-data صرفاً تأیید دستی است و بررسی خودکار انجام نمی‌دهد.

خروجی فعلاً تصمیم‌هاست، نه سود واقعی یا بک‌تست معتبر. هیچ سفارش واقعی ارسال نمی‌شود.
